# Rufus

**Status:** Planned  
**Technologies:** Embedded Systems · Analog Electronics · ECG · Pulse Oximetry · Signal Processing

## Overview

Rufus is a multiparameter vital signs monitor prototype intended to acquire and display physiological signals, including ECG, heart rate, and oxygen saturation. I am designing it as a biomedical engineering project inspired by bedside and transport monitors, with an emphasis on sensor circuitry and real-time waveform processing.

The name **Rufus** references Rufus of Ephesus, an ancient Greek physician whose work included anatomy and the study of the pulse.

## Key Design Choices

- **Multiple measurements:** Combine ECG acquisition with optical pulse-oximetry sensing and derived vital signs.
- **Signal processing:** Separate analog acquisition, digital filtering, measurement calculations, and visualization.
- **Modular instrumentation:** Allow individual sensor channels to be developed and validated independently.
- **Safety boundary:** Treat the device as an engineering prototype, not a clinically validated patient monitor.
